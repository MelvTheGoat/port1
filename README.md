# Oluwatobi Mayungbo, Portfolio

React + Vite + Tailwind.

- Run locally: `npm install` then `npm run dev`
- Edit projects: `src/data/projects.ts`
- Edit skills: `src/components/Skills.jsx`
- Edit intro and links: `src/components/Hero.jsx` and `src/components/Contact.jsx`
- Replace the resume: overwrite `src/assets/Resume.pdf`
- Deploy: push to `main`, then in the repo go to Settings > Pages > Source and choose **GitHub Actions**.
